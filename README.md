# Tiny Expedition Village

Mobile-first H5 prototype for a cozy animal village roguelite.

## Live Page

After the GitHub Pages workflow completes, the public site URL is:

`https://pantianhao99-max.github.io/gaga/`

## Files

- `index.html`: single-page mobile prototype shell
- `styles.css`: cozy vertical game UI styling and motion
- `script.js`: village, expedition, battle, upgrade, and codex interactions
- `.github/workflows/deploy-pages.yml`: GitHub Pages deployment workflow
